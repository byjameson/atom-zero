# atomzero 0.1.9 - support and onboarding polish

Status: **published to PyPI as `atomzero 0.1.9` on 2026-11-22.**

Product polish release. No model or runtime behavior changed; the weights remain
`0.8.0`.

## What changed

- Added donation addresses to the README, PyPI description, Hugging Face and
  ModelScope model cards, project overview and articles.
- Added `atomzero-quickstart --reset-demo`.
- Added `atomzero --version` and `atomzero-quickstart --version`.
- Added `docs/TROUBLESHOOTING.md`.
- Kept `atomzero-doctor` from 0.1.8.

## Install

```powershell
pip install atomzero==0.1.9
atomzero-doctor
atomzero-quickstart
```
